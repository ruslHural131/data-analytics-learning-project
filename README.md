  # Data Analytics Learning Project

Edukacyjny projekt analityczny łączący SQL, Power BI, Tableau i Jira.

  ## Cel projektu

Pokazanie pełnego cyklu pracy analityka danych:
- baza danych;
- analiza;
- wizualizacja;
- zarządzanie projektem;
- prezentacja wyników.

  ## Narzędzia

- SQL / MySQL
- Power BI
- Tableau
- Jira
- Excel

  ## Struktura projektu

- `sql/` — skrypty SQL
- `data/` — dane podsumowujące
- `powerbi/` — dashboard Power BI
- `tableau/` — dashboard Tableau
- `jira/` — podsumowanie projektu
- `presentation/` — link do prezentacji
